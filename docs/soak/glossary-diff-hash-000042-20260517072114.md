`pre_exec_diff_hash` is a hash computed from the git diff of the working tree immediately before an execution step begins at the wired-loop boundary. `post_exec_diff_hash` is the corresponding hash computed from the git diff immediately after that execution step completes. Together, these hashes capture the exact state delta introduced by a single loop iteration. They are computed against git diff at the wired-loop boundary to ensure reproducible tracking of changes across the isolated worktree. By comparing the pre- and post-execution diff hashes, downstream systems can deterministically verify what modifications were produced by a specific execution provider invocation.
