The OpenCode + Kimi K2.6 dispatcher is the current default inference provider, routing all generation requests through OpenRouter to the moonshotai/kimi-k2.6 model. OpenRouter’s unified API handles load balancing and failover across underlying inference providers. Before each request leaves the execution environment, the shell context is scrubbed to remove secrets, API keys, and sensitive environment variables. The dispatcher operates within an isolated git worktree owned by Ralph, meaning it only modifies explicitly requested file paths and never runs deployment or merge commands. After processing, the worktree is left in a clean state so Ralph can capture the candidate patch via git diff.
