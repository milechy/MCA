`plan_hash` is a deterministic identifier computed from an execution plan by first serializing the plan into canonical JSON with sorted keys and normalized whitespace, then taking the SHA-256 digest of that JSON string. The resulting digest is typically represented as a lowercase hexadecimal string, often truncated to a convenient prefix for display or indexing purposes. Because the serialization uses canonical JSON, semantically identical plans—those differing only in insertion order of object keys or trivial formatting—will always produce the same hash. This stability enables reliable deduplication, caching, and idempotency checks across pipeline stages. The `plan_hash` therefore serves as a compact, collision-resistant fingerprint that uniquely identifies a plan's intent regardless of how it was constructed.
