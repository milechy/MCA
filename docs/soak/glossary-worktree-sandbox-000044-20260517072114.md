The per-story git worktree sandbox is an isolated, temporary git worktree created for each soak story execution. It ensures complete filesystem isolation, preventing any modifications to the primary workspace. To safeguard the host environment, the sandbox operates under a strict path-prefix allow-list, where only paths under the configurable `sandbox_root` directory may be accessed, written, or created. All tooling invoked inside the sandbox must respect this boundary and refuse any operation outside the allowed prefix. Upon completion—regardless of success, failure, or cancellation—the sandbox is subject to unconditional teardown, removing all temporary files and directories. This guarantees no residual state leaks between successive story runs and keeps the environment reproducible.
