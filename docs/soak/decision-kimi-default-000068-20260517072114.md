# ADR-2026-05-14: Promote OpenCode + Kimi K2.6 to Default; Demote NemoClaw to Opt-In

## Status
Accepted

## Context
We maintain multiple execution providers for the soak pipeline. Historically, **NemoClaw** served as the default provider. We have since integrated **OpenCode** paired with the **Kimi K2.6** model (via OpenRouter) and observed sufficient reliability and performance across soak runs to justify a promotion.

## Decision
- **Promote** the OpenCode + Kimi K2.6 execution provider to the **default** soak provider.
- **Demote** NemoClaw to an **opt-in** provider for scenarios where it is explicitly requested.

## Consequences
- Soak jobs that do not specify a provider will now run under OpenCode + Kimi K2.6 instead of NemoClaw.
- NemoClaw remains available for targeted or legacy soak configurations but is no longer the implicit default.
- Monitoring and rollback procedures should apply to the new default going forward.
