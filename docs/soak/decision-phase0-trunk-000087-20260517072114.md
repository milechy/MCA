# Decision: Canonical Trunk for Phase 0/1

**Date:** 2026-05-17
**Status:** Accepted

## Decision

During Phase 0 and Phase 1, the branch `infra/phase0-autonomous-foundation` serves as the **canonical trunk**.

## Context

- The repository's `defaultBranchRef` points to `infra/phase0-autonomous-foundation`.
- A `main` branch does **not yet exist**.
- All integration, tagging, and release activities for Phase 0/1 should target `infra/phase0-autonomous-foundation`.

## Consequences

- Contributors must base new work on `infra/phase0-autonomous-foundation`.
- CI/CD pipelines should treat `infra/phase0-autonomous-foundation` as the primary branch.
- When Phase 1 concludes, a `main` branch may be created and promoted to `defaultBranchRef`.
