pre_exec_diff_hash
: The SHA-256 hash of the `git diff` output captured immediately before an execution provider (e.g., Kimi K2 via OpenRouter) begins processing a task inside a Ralph worktree. It represents the repository state at the wired-loop boundary just prior to code generation.

post_exec_diff_hash
: The SHA-256 hash of the `git diff` output captured immediately after an execution provider finishes processing and the worktree has been modified. It represents the repository state at the wired-loop boundary just after code generation, and the delta between `pre_exec_diff_hash` and `post_exec_diff_hash` constitutes the candidate patch.
