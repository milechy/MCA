The Ralph execution provider dispatches tasks to the Kimi K2.6 model by default, routing all requests through the OpenRouter API gateway. This dispatcher is the current default provider within the Ralph worktree orchestration system. OpenRouter handles model selection and load balancing, ensuring requests reach the appropriate Kimi K2.6 endpoint with minimal latency. To prevent leakage of sensitive environment variables, all requests undergo a strict env scrubbing step before being sent upstream. The integration leverages OpenCode as the local execution layer, which translates task instructions into structured API calls compatible with OpenRouter's specification. Failed requests are automatically retried with exponential backoff, while respecting OpenRouter's rate limit headers.
