The `plan_hash` is a deterministic identifier computed for an execution plan to verify its structural identity. It is derived by serializing the plan into canonical JSON format, ensuring consistent key ordering and whitespace rules so that logically equivalent plans produce identical byte representations. The resulting JSON string is then hashed using SHA-256, and a fixed-length prefix of that digest is used as the `plan_hash` value. This design guarantees that semantically identical plans—those that differ only in non-material ways, such as transient metadata or field ordering—will always yield the same hash. Consequently, `plan_hash` remains stable across rebuilds, re-serializations, and different environments as long as the underlying plan semantics have not changed. It serves as a compact, content-derived fingerprint for caching, deduplication, and traceability purposes.
