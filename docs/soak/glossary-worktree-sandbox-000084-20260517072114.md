The **per-story git worktree sandbox** is an isolated filesystem environment Ralph creates for each coding story, using Git worktrees to guarantee that all file changes are scoped, reviewable, and captured as a unified diff. Every sandbox is rooted beneath a configurable `sandbox_root` directory; only paths carrying this prefix are eligible for reads or writes, forming an explicit allow-list that blocks accidental access outside the workspace. Regardless of whether a story completes successfully, errors out, or is interrupted mid-flight, Ralph performs an unconditional teardown of the sandbox, releasing the Git worktree and clearing all transient artifacts. This ensures no leftover files or state leak between stories and that the final `git diff` reflects solely the intended modifications. The `sandbox_root` prefix restriction is enforced at the tool layer, so any agent request targeting an off-limits path is rejected before execution.
