`pre_exec_diff_hash` is a SHA-256 hash computed from the `git diff` of the worktree immediately before an execution step begins, captured at the wired-loop boundary (the point where control passes into the execution phase). It represents the delta between the committed state and the working directory at that instant. `post_exec_diff_hash` is the corresponding hash computed from the `git diff` after the execution step completes, again captured at the wired-loop boundary. Together, these two hashes allow the system to deterministically verify whether the execution step itself produced any changes to the worktree. If `pre_exec_diff_hash` equals `post_exec_diff_hash`, the step is considered idempotent with respect to the filesystem.
