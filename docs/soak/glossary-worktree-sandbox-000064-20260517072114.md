A per-story git worktree sandbox is a dedicated working directory tied to a specific task or story, providing an isolated environment for file operations, builds, and testing without affecting the main working tree or other concurrent tasks. Each sandbox is created under a designated `sandbox_root` directory, which is guarded by a prefix allow-list that prevents accidental writes to paths outside the permitted hierarchy. For example, only directories starting with `/var/tmp/opencode-sandbox/` are accepted, rejecting any attempt to target system or user directories. When a sandbox is initialized, the current HEAD is checked out into the new worktree, giving the task a fresh, replayable starting point. To prevent disk and worktree sprawl, every sandbox is subject to unconditional teardown: it is removed automatically when the task completes, regardless of success or failure. This ensures no leftover artifacts persist across runs and simplifies cleanup logic.
