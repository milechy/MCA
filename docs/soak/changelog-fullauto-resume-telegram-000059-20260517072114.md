Added a fullauto auto-approver that evaluates each step with an LLM to decide whether it can proceed without human confirmation, reducing the need for constant supervision. Introduced a resume-after-security-stop mechanism so that when the system halts due to a security concern, execution can later pick up where it left off rather than restarting from the beginning. Exposed Telegram bot commands `/resume-request` and `/resume-status`, allowing users to query the current resume state and request continuation directly from chat.
