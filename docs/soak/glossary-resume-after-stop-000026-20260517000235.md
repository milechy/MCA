The **resume-after-security-stop** workflow is a manual recovery path that allows an operator to continue a halted soak test after a security-related pause. Access to this workflow is restricted to admin-level users and requires explicit manual approval. Each invocation is single-use: once the test resumes, the stop token is consumed and cannot be reused for another resumption from the same halt point. The workflow intentionally never enables or transitions the system into `fullauto` mode, preserving human oversight over security-sensitive restarts. Upon successful execution, the soak test continues from its last known checkpoint without resetting accumulated state. All resumption actions are logged for audit purposes.
