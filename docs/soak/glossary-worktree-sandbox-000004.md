A per-story git worktree sandbox is an isolated working directory created by Ralph for each task (story) execution, ensuring that changes made by the agent do not interfere with the main repository or other stories. The sandbox_root path acts as a prefix allow-list, confining the agent to operate only within its designated directory and preventing unauthorized access to the host filesystem. After the story completes—whether successfully, with failures, or on cancellation—the sandbox undergoes unconditional teardown to guarantee no residual state persists between runs. This ephemeral, self-contained environment enforces strict isolation from the target codebase while still preserving the underlying git history via the worktree mechanism.
