# plan_hash

A **plan_hash** is a deterministic identifier generated from a Canonical JSON representation of a candidate plan. It is computed by serializing the plan's essential fields—such as intention, scope, and resources—into a stable, sorted, canonical JSON format, then hashing the resulting string.

The hash function used is SHA-256, and by convention the identifier is represented by a fixed-length prefix of the full digest (e.g., the first 16 hex characters). Because the serialization excludes non-semantic metadata (timestamps, ephemeral identifiers, etc.), the hash remains **stable across semantically identical plans**: two plans that differ only in irrelevant details will produce the same `plan_hash`, enabling reliable deduplication and traceability.
