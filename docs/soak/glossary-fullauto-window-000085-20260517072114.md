Fullauto Window

The **fullauto window** defines the maximum continuous duration that an operation or process may run in fully-automated mode before requiring renewed administrative consent. When a deployment or soak test enters fullauto, it defaults to a runtime governed by `DEFAULT_FULLAUTO_HOURS=6`, providing a six-hour baseline of unsupervised execution. If an admin explicitly confirms, the window can be extended up to the hard ceiling set by `MAX_FULLAUTO_HOURS=24`, allowing a full day of automated activity at most. This two-tiered boundary ensures that short-lived tasks proceed efficiently while preventing indefinite, unreviewed automation. Admin confirmation acts as a safety gate, enforcing human oversight before any run exceeds the default limit. Together these constants create a predictable, bounded automation lifecycle that balances throughput with operational safety.
