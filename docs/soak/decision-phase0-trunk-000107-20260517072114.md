# Decision: Canonical Trunk for Phase 0/1

**Date:** 2026-05-17

**Decision:** During Phase 0 and Phase 1, `infra/phase0-autonomous-foundation` is the canonical trunk branch.

**Rationale:**
- The repository's `defaultBranchRef` currently points to `infra/phase0-autonomous-foundation`.
- A `main` branch does not yet exist in the repository.
- All trunk-based development, integration, and release cutovers should treat `infra/phase0-autonomous-foundation` as the authoritative source of truth until `main` is introduced in a later phase.

**Consequences:**
- CI/CD pipelines, branch protection rules, and automated soak tests should target `infra/phase0-autonomous-foundation` as the default integration branch.
- When `main` is eventually created and promoted, this decision should be revisited and updated.
