# Per-Story Git Worktree Sandbox

The per-story git worktree sandbox is a dedicated, isolated git worktree that is provisioned for each Ralph story execution. A `sandbox_root` prefix allow-list constrains which paths within the worktree may be modified by the execution agent, preventing unintended changes outside the explicitly allowed directories. Every story execution operates entirely within this isolated worktree, ensuring that concurrent or sequential runs do not interfere with the main repository state. Upon completion of the story—regardless of success, failure, or cancellation—the worktree undergoes unconditional teardown and removal. This teardown ensures no transient artifacts, partial changes, or untracked files persist on the host system. The combination of path-scoped access controls and guaranteed cleanup makes the worktree sandbox a safe, reproducible, and stateless execution environment.
