Phase 1 (PRs #45–#53) established the Kimi K2.6 execution pipeline as Ralph's production default, starting with worktree sandboxing, stuck-loop recovery, and a soft-timeout downgrade that prevented false runtime failures when valid patches were already captured (#45–#46). A successful 24-story Phase 0 soak validated the pipeline with 19/19 clean patches and zero escalations, followed by documentation of the implementation design in v0.2 and the soak findings (#47–#48). The end-to-end autonomous chain was then completed with fullauto auto-approval gated by risk bounds (#49–#50), an admin-only `RESUME_AFTER_SECURITY_STOP` workflow to recover security-stopped stories (#51), and full Telegram command coverage so operators can drive approvals, mode changes, and story recovery without host access (#52). Finally, NemoClaw was retired as the default mediator after an ADR documented its inert status, leaving the OpenCode+Kimi K2.6 direct dispatcher as the sole production path (#53).
