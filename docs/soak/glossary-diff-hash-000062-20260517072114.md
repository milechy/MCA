## pre_exec_diff_hash

A pre_exec_diff_hash is the SHA-256 digest of the unified `git diff` captured against the repository index immediately before an execution edge crosses the wired-loop boundary. It reflects any uncommitted changes present in the worktree at the entry point of the loop, serving as a cryptographic snapshot of the codebase state prior to mutation by the agent.

## post_exec_diff_hash

A post_exec_diff_hash is the SHA-256 digest of the unified `git diff` captured against the repository index immediately after an execution edge exits the wired-loop boundary. By comparing it with the corresponding pre_exec_diff_hash, the system can deterministically verify what artifacts the agent produced during its bounded run.
