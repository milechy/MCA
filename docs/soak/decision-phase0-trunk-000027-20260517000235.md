# Decision: Canonical Trunk for Phase 0/1

## Decision

During Phase 0 and Phase 1, the branch `infra/phase0-autonomous-foundation` is designated as the canonical trunk.

## Rationale

This branch serves as the primary integration point while the autonomous foundation infrastructure is being established. It consolidates early-phase work before the repository transitions to a more conventional branching model.

## defaultBranchRef

The `defaultBranchRef` for the repository currently points to `infra/phase0-autonomous-foundation`. This reflects its role as the default target for merges and the source of truth for ongoing development.

## Note on `main`

The `main` branch does not yet exist. It will be introduced in a later phase once the foundational infrastructure stabilizes and the project is ready to adopt the standard `main`-based workflow.
