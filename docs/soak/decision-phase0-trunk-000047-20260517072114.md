# Decision: Canonical Trunk for Phase 0/1

**Date:** 2026-05-17  
**Decision ID:** 000047  
**Status:** Accepted

## Context

During the early phases of the project (Phase 0 and Phase 1), the repository does not yet contain a `main` branch. The foundational infrastructure must be established before the conventional default trunk can be introduced.

## Decision

The branch **`infra/phase0-autonomous-foundation`** is designated as the **canonical trunk** for Phase 0 and Phase 1.

## Rationale

- `main` does not yet exist in the repository at this stage.
- All integration, autonomous soaking, and trunk-aligned work shall target `infra/phase0-autonomous-foundation` as the effective `defaultBranchRef`.
- This provides a stable integration point while the foundational architecture is being laid.
- Once Phase 1 completes and the foundation is solidified, a conventional `main` branch can be created and promoted to `defaultBranchRef`.

## Consequences

- CI/CD configurations, soak pipelines, and merge targets must reference `infra/phase0-autonomous-foundation` rather than `main` during these phases.
- Transition planning must include a migration path from `infra/phase0-autonomous-foundation` to `main` at the end of Phase 1.
