The fullauto window is a configurable time period during which an administrator can enable autonomous operation after explicit confirmation. By default, this window is set to six hours, using the `DEFAULT_FULLAUTO_HOURS=6` setting. An administrator must confirm the action to activate the fullauto mode within this window. The maximum allowable duration for the fullauto window is twenty-four hours, defined by `MAX_FULLAUTO_HOURS=24`. This design ensures that autonomous operations remain bounded and require periodic re-authorization by an admin.
