OpenCode — Kimi K2.6 Dispatcher (default)

The dispatcher routes soak tasks to the Kimi K2.6 model via the OpenRouter API, accessed through the OpenCode execution provider. Requests are proxied through OpenRouter’s unified endpoint, which automatically load-balances across the underlying model provider while maintaining a consistent chat-completion interface. Before dispatching any request, OpenCode scrubs sensitive environment variables including API keys, tokens, and any values matching known secret patterns from both the prompt context and the runtime environment, ensuring that credentials never leave the execution sandbox. Responses are streamed back asynchronously, with OpenCode applying token-usage limits and timeout guards to prevent runaway consumption. This setup serves as the current default for the soak pipeline, chosen for its balance of reasoning depth, context-window capacity, and cost efficiency relative to frontier alternatives.
