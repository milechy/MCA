# plan_hash

A `plan_hash` is a deterministic identifier generated from a task plan's canonical JSON representation. It is computed by serializing the plan into JSON with keys sorted in lexicographic order and arrays preserved, then applying the SHA-256 hash algorithm to the resulting byte string. The resulting hash is truncated to a fixed prefix (typically the leading 12–16 hex characters) to produce the final `plan_hash`. This design guarantees that any two semantically identical plans—regardless of field ordering or whitespace differences in the original representation—will produce the same hash value. Because the normalization step removes non-semantic variance, the `plan_hash` remains stable across different build systems, serialization libraries, and formatting conventions. It is used to deduplicate task plans, detect changes across rebuilds, and cache plan-dependent artifacts with high confidence.
