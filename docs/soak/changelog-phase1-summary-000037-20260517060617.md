Merged PRs #45 through #53, completing Phase 0 and the first five Phase 1 milestones of the Ralph autonomous-loop infrastructure. PR #45 introduced the OpenCode + Kimi K2.6 direct dispatcher with per-story git worktree sandboxing and a deterministic fallback for stuck-loop recovery, while #46 tightened the dispatcher contract and soft-timeout logic, enabling the 24-story Phase 0 soak (#48) that produced 19/19 clean candidate patches with zero escalations or worktree leaks at roughly $0.14 total cost. PR #47 published the Ralph detailed design v0.2 specification, and #49–#52 extended the loop end-to-end through autonomous PR creation, fullauto mode with risk-bounded auto-approval, the RESUME_AFTER_SECURITY_STOP recovery workflow, and Telegram bot operator control. Finally, #53 promoted the Kimi-direct dispatcher to the system default and retired NemoClaw to an opt-in legacy path, aligning the documented architecture with the validated production reality observed since #45. All changes preserve the existing policy boundary where apply, commit, push, merge, deploy, and migration remain disallowed at the dispatcher level, and every new path is covered by dedicated unit tests.
