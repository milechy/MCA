# Decision: Canonical Trunk During Phase 0/1

**Record ID:** decision-phase0-trunk-000067
**Date:** 2026-05-17

## Context

During the initial phases of the project (Phase 0 and Phase 1), the repository does not yet have a traditional `main` branch. The ongoing infrastructure and foundation work lives on a feature branch that serves as the integration point.

## Decision

The branch **`infra/phase0-autonomous-foundation`** is designated as the **canonical trunk** for Phase 0 and Phase 1.

- This branch acts as the effective `defaultBranchRef` for the repository during these phases.
- All integration, deployment previews, and autonomous-soak workflows should target this branch as the source of truth.
- A `main` branch **does not yet exist** and will only be created once the foundation work is complete and the project transitions out of Phase 1.

## Consequences

- CI/CD configurations and soak runners must reference `infra/phase0-autonomous-foundation` explicitly, or resolve the current `defaultBranchRef`, rather than assuming `main`.
- Any tooling that expects a `main` branch must be configured to tolerate its absence or to treat `infra/phase0-autonomous-foundation` as the fallback trunk.
- When Phase 1 concludes, this decision should be revisited to establish `main` as the canonical trunk.
