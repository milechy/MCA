# Fullauto Window

The **fullauto window** is a configurable time period during which an admin-elevated session remains active without requiring additional confirmation steps. Once an administrator elevates their privileges, the system grants a default grace period of `DEFAULT_FULLAUTO_HOURS=6` hours, during which subsequent privileged operations proceed automatically. This window reduces friction for repeated administrative tasks while still enforcing security boundaries. The maximum allowable duration is capped at `MAX_FULLAUTO_HOURS=24` hours to prevent indefinite unconstrained access. If an admin triggers a sensitive action after the window expires, the system re-prompts for explicit confirmation before proceeding. Administrators can review or revoke an active fullauto session at any time through the admin dashboard.
